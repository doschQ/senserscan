Deine Daten bleiben auf diesem Gerät

Jede App speichert deine Eingaben nur im Browser dieses Geräts. Kein Server empfängt oder speichert sie. Wenn du die Websitedaten des Browsers löschst, sind sie weg – sichere wichtige Stände über den Export der jeweiligen App.

Auf den Home-Bildschirm legen

iPhone: in Safari auf Teilen → „Zum Home-Bildschirm“. Android: im Chrome-Menü „Zum Startbildschirm hinzufügen“. Öffne die Apps danach immer über dieses Symbol – auf dem iPhone hat es einen eigenen Speicher, getrennt von Safari.
